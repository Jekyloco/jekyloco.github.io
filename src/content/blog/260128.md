## 📝 02. 文本与段落 (Typography)

为了达成最佳的阅读体验，我们遵循 **“盘古之白”** 原则：在中英文混排时保持空隙。

* **重点强调：** 使用 `**加粗**` 突出核心词汇，使用 `*斜体*` 标注外来术语。
* **行内视觉：** 关键变量或文件名应包裹在 `code` 标签中，如 `/src/pages/index.astro`。
* **交互细节：** 如果提到快捷键，请务必使用 HTML 标签：按下 `<kbd>`Ctrl `</kbd>` + `<kbd>`Shift `</kbd>` + `<kbd>`P `</kbd>`。

## 💻 06. 代码工坊 (Code Blocks)

为代码块添加文件名注释（虽然是注释，但能显著提升可读性）。

```typescript
// @file: auth-service.ts
/**
 * 校验用户访问权限
 * @param user 当前用户对象
 */
export const checkAccess = (user: User): boolean => {
  return user.role === 'admin' && user.isActive;
};
```
